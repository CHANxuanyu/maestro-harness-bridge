# v1.0.1-hb.5 · 更可靠的原生接续、跟随与历史

当前是源码候选说明，尚未打包或发布。完成 Mac 验收后，按实际结果更新草稿 Release 的验证段；不要把下文待验项改成预期通过。

## 产品变化

- Codex 与 Claude 的历史接续保留原生工具输入、结果、失败与停止状态，以及每轮模型。摘要不会再向 Codex 共享会话追加 Summary；Claude 摘要沿用不落盘的调用。
- 本地会话在另一端追加后能跟随刷新；大量历史优先读取最近窗口，保留草稿、队列和阅读位置。长会话工具配对及大量会话搜索减少了重复读取。
- 会话浏览器的搜索、预览和接续保持所选账户；账户目录不存在时明确提示，切换账户后旧预览和迟到结果不会覆盖新账户。缺少原生时间时显示未记录，导出和 CLI 不再虚构零时长。
- 信息流保留模型和停止信息，命令输出支持跟随与手动上滚；未读数不再计入工具行，窄窗口布局和打开会话后的输入焦点也已改善。
- 共享连接器增加命令输出增量、状态与回合隔离和明确的版本准入检查。未经 Mac 验收的版本仍不能日常启用。其他提供方的源码改进及限制见[完整变更](../../CHANGELOG.md)。

本候选不包含后续的 DeepSeek 预设、跨 AI 交接和“关于我”。候选合并提交是唯一构建来源，不能用后续主线替代。

## 下载、升级与启动

发布后从[本仓库 Releases](https://github.com/CHANxuanyu/maestro-harness-bridge/releases)下载 `Maestro-I18n-1.0.1-hb.5-mac-arm64.zip`，先核对 `SHA256SUMS.txt`。macOS Apple Silicon 专用，临时签名且未公证。

正常退出旧版，备份 `~/Library/Application Support/Maestro I18n`，再解压并替换应用；不要同时运行两个同名版本。首次打开可按 macOS 的“隐私与安全性”提示放行。原生 CLI 仍需自行安装并登录，Maestro 不提供共享订阅或认证。应用名称和 bundle ID 保持不变，继续读取原配置；本候选没有新增配置迁移。

共享连接器是独立附件 `Maestro-Codex-Shared-1.0.1-hb.5.zip`，不会随应用替换而启用。它的实现较 hb.4 有变化，需按[双端说明](../codex-shared.md)正常退出、检查原生版本后再选择启用。仍仅准入 `codex-cli 0.163.0-alpha.11.1` 与已核对的 ChatGPT 桌面布局，不扩大版本范围。

回退时先结束任务与队列，正常退出应用，备份当前配置，再恢复 hb.4 应用及升级前配置备份。若切换了连接器，先按双端说明执行对应目录的 `disable-sharing.command`，恢复原有自定义可执行路径和旧连接器目录。不要删除原生历史或写锁。升级后产生的原生会话由原生 CLI 保存，不以删除记录作为回退手段。

## 验证与已知限制

Linux/Windows 自动检查及 Linux 合成 Electron 用例只覆盖源码和隔离假程序，不能代替发行包与真实账户验收。[hb.5 验证记录](../verification/v1.0.1-hb.5.md)包含核心流程清单、七项 CI 的追溯方法和 Mac 操作顺序；[工作记录](../worklog.md)保留实施范围。

- Claude Code 真实模式锁定 `2.1.310`，Codex 锁定 `0.163.0-alpha.11.1`。真实账户、macOS 桌面、发行包签名/原生模块和整条双端 GUI 序列在云端未验。
- 共享仅支持同账户、同主机的已有本地 Codex 会话顺序接续；新建、分支、远程共享和并发发送不支持。SSH 历史仍按已配置主机读取，不属于本次本地自动跟随验收。
- Stop 中断原生回合，不保证已启动的终端进程立刻退出。Claude API 摘要若被残留 thinking 空壳拒绝，走现有 `Synopsis failed`，Maestro 不重试或改成本地摘要；下一次正常 API 回合清理后该空壳原因消失。
- 其他提供方的格式和账户边界见[原生契约](../native-provider-contracts.md)，合成用例通过不等于真实服务可用。共享桌面更新后先运行版本检查，未知版本不能绕过准入。

发布时附五项资产：应用 ZIP、连接器 ZIP、`BUILD-MANIFEST.json`、`VERIFICATION.json`、`SHA256SUMS.txt`。它们必须来自同一冻结提交和实际构建字节；不得包含真实对话、账户文件、截图或原始日志。
