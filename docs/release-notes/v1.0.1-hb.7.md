# v1.0.1-hb.7 · 项目、对话与跨家接力的试用候选

这是给同时使用 Claude Code、Codex 和 DeepSeek 的用户准备的新界面候选。新界面默认关闭，旧界面仍可使用。2026-11-12 已在本机从主线构建试用包并做包内验证（见验证与已知限制），尚未打标签、上传或发布。

## 产品变化

- 新界面按项目列出对话，中间去掉标签栏，可以并排查看两条对话。左栏支持本机内容搜索、归档和重新打开历史；首次打开提供项目入口与最近项目。
- 右栏集中改动、文件、终端、任务和网页。改动可以按回合查看、暂存、撤销和提交；文件可编辑保存；网页按对话保存网址，本机输出链接进入右栏。
- “交给…”和“让另一家复核”复用同一交接流程。同窗口子任务能点开、插话和继续；跨窗口新建子任务由目标窗口保存来源后回执。项目可选择额度用尽后的自动交接目标，默认关闭，并显示所用工具与账户。
- 项目设置分别管理新对话默认值与各份工具配置，包含账户目录、程序、参数、环境变量、Claude 调用方式和 SSH 主机。保存读取最新配置，避免旧编辑窗口将 CLI 刚改过的值覆盖。
- 新界面停止按目标对话隔离，审批框可直接“停止这一轮”；`tab stop` 与界面共用完整停止处理。主动停止不再发完成通知，新旧界面都适用；旧界面停止按钮不再因点击事件误判目标而失效。Claude 的本机标准权限提供单次允许和拒绝；Codex 的本地审批与本轮追加仍是默认关闭的独立原型。
- 修复长历史、权限继承、原生命令刷新、即时退出草稿保存和额度探针退出问题。连续输出减少重复处理；流式输入延迟的退化信号经七轮对比没有重现，不能宣称性能全面改善。

完整条目见 [CHANGELOG](../../CHANGELOG.md)。路线图的 hb.7、hb.8 阶段已有部分能力一起进入本候选，不表示后续默认切换和删除旧功能已经完成。

- 按原规格补齐：手机网页的新界面窄屏形态；交接会话挂在来源下面，归档来源时回到顶层；新界面所有操作都有对应命令行；界面切换保留终端、进程和草稿；项目设置事务式保存；SSH 下改动面板、文件、终端和交接经过实测。

## 下载、升级与启动

本候选为 macOS Apple Silicon 试用包 `Maestro-I18n-1.0.1-hb.7-mac-arm64.zip`（248,293,192 字节，SHA-256 `e3302c6db30a5c09cc41bd0cf41653f12027ed14563c227639f03fd7a43f3209`），临时签名、未公证，尚未上传。其他平台没有本候选的安装验收。当前可下载的历史包见 [hb.6 Release](https://github.com/CHANxuanyu/maestro-harness-bridge/releases/tag/v1.0.1-hb.6)，它不包含本轮新界面。

候选提供后再执行以下步骤：

1. 校验实际 Release 所附 `SHA256SUMS.txt` 和包身份。正常退出 Maestro，备份当前应用配置和旧应用副本，再替换 `Maestro I18n.app`，不要同时启动两个同名版本。
2. 从 Finder 打开 `Maestro I18n.app`。先核对关于页版本、原项目、历史和草稿。签名或系统阻止打开的处理以实际构建结果为准，本候选不预填公证结论。
3. 在“设置 → 显示 → 新界面”打开开关，或在运行中的桌面应用旁执行 `maestro-cli settings set newShell true`。不需要重启。新界面开关与 `codexAppServer` 是两个开关，打开新界面不会自动启用 Codex 原型。
4. 原生 Claude Code、Codex 仍需各自安装和登录，使用原有账户与额度。现有可用配置继续读取；本轮不要求激活共享连接器，不将 app-server 的验证扩大为共享连接器版本准入。连接器包身份与兼容性待构建核对，历史范围见 [Codex 共享说明](../codex-shared.md)。

更新继续从本分支 Release 手动下载，不通过上游更新渠道安装。正式试用前应完成[候选包清单](../verification/v1.0.1-hb.7.md#待做的包内验证)，原配置升级启动与全天使用目前未验证。

回退界面：关闭同一个设置，或执行 `maestro-cli settings set newShell false`，无需重启。切换会清空终端的显示缓冲，进程不停止，先保存需要的终端输出。若 Codex 对话保存了标准权限，关闭原型或退回旧界面后会拒绝启动；按需要显式选择支持的权限，不会自动扩大权限。

回退应用：正常退出 hb.7，另存一份当前配置，再恢复 [hb.6 应用](https://github.com/CHANxuanyu/maestro-harness-bridge/releases/tag/v1.0.1-hb.6)。如需恢复配置，使用升级前的备份，保留升级后的副本以免丢失试用期间记录。hb.7 配置直接交给 hb.6 的降级兼容性未验证；不要删除原生历史或写锁。hb.6 的签名与验证事实见其[版本说明](v1.0.1-hb.6.md)。
