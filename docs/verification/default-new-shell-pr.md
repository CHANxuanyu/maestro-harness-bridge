# PR 标题

准备 hb.9 默认新界面、旧功能删除清单和安装包基线

# PR 正文

此 PR 等待用户完成真人体验并明确同意后才可合并。它只提交在 `codex/default-new-shell`，不改变当前主线，也不删除旧功能或用户数据。旧界面至少保留默认切换发布后的一个版本。

新安装和升级默认进入新界面。历史 electron-store/conf 已把默认 false 写入文件，无法分辨用户意图，因此无 `newShellChoice` 标记时执行一次迁移。此后设置开关、在线 CLI 和离线 CLI 都把布尔值与显式选择一起写入，用户选回旧界面后重启仍保留。经典界面的行为和入口继续保留。

删除计划涵盖十项上游功能及旧界面，附生产 import 边和测试候选清单，明确跨工具委派、原生历史、MCP、浏览器安全和渲染组件的共用依赖。没有执行删除。新增只读 macOS 包基线脚本，报告 ZIP/bundle/asar 字节数，以及隔离数据目录下到首窗 renderer ready 的启动样本和中位数。

验证对象为本分支源码，没有构建或运行新发行包。完整命令、失败先行记录和局限见 [Task N 验证记录](default-new-shell.md)。类型检查、ESLint、改动文件 Prettier、相关 810 项 Vitest 和基线 5 项 Node 测试通过；夹具全套 80 项通过、3 项受沙箱 Unix socket EPERM 阻塞。新增和更新的 Electron 场景仅完成收集，未声称通过。hb.7 实际包基线、Electron 验收、分支 CI 和用户决定均未完成。
