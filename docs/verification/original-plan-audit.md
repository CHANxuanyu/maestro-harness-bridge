## 新界面 CLI 对等缺口（A20 的明细）

这些是新界面里能点、但命令行做不到的动作，按原规格都要补：

1. 打开内容搜索的命中并跳到那条消息；设置和清空左栏搜索。
2. 读取任务面板当前显示的清单和空状态。
3. 展开、收起子任务树；对已关闭的来源按原生 id 查子任务。
4. 打开、关闭项目设置窗口。
5. 新建会话并直接分屏。
6. 排队消息的“强制发送”。
7. 刷新原生历史。
8. `session list` 和 `tab show` 在切换会话后读到过时的“当前”会话。
