## 新界面 CLI 对等（A20 的明细，均已补齐）

1. 打开内容搜索的命中并跳到那条消息：`native-history open-hit`；设置和清空左栏搜索：`ui sidebar-search`。
2. 读取任务面板当前显示的清单和空状态：`tab tasks`。
3. 展开、收起子任务树：`tab children --expand/--collapse`；已关闭来源按原生 id 查子任务：`tab children --native`。
4. 打开、关闭项目设置窗口：`open project-settings`。
5. 新建会话并直接分屏：`tab new --split`。
6. 排队消息的强制发送：`queue force-send`。
7. 刷新原生历史：`tab refresh`。
8. 切换会话后立即读取当前会话：`session list`、`tab show` 读所属窗口的实时状态。

## 收尾中新发现并修复的缺陷

- SSH 下改动面板点开的差异被后台刷新收起（SSH 场景发现）。
- 没有显式标签参数的启动漏带调用方标签，派出的子任务记不到来自哪条对话（真实 Codex 主控场景发现）。
- 从旧界面终端标签切回新界面时输入框消失（界面切换场景发现）。
- 默认开启新界面时，窗口恢复覆盖对话保存的面板开合状态（只在默认切换分支上出现，已在该分支修复）。
