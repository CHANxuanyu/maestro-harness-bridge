## 原生会话的真实界面验收

最终序列在 2026-10-21 01:39–01:55 完成。由独立控制聊天操作真实 macOS 界面，原始 Codex 会话在桌面客户端真实释放写入占用之后才发送。过程中没有删锁、静默分支或用另一条验收会话替代原始对话。

| 检查               | 实际结果                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 原始上下文与多轮   | 在原始历史上连续发送，能够复述既有项目状态/分工，并跨轮次记住新测试口令。                         |
| 工具和公开进度     | 依次执行两个有界只读终端工具，两次中间显示公开进度；工具输入、完整结果与顺序可展开核对。          |
| 界面停止           | 在等待命令运行期间点击停止，界面显示用户停止，原生历史包含取消事件；没有自动重试。                |
| 停止后恢复         | 仍在原 ID 发送下一轮并收到正常回复，保留此前口令与上下文。                                        |
| 正常退出与重开     | 通过应用菜单退出，核实旧进程结束后重新启动；原 ID、账户和主机归属保持，发送后仍能回忆停止后回复。 |
| 旧历史主动发送     | 从历史阅读位置发送后进入新回合并跟随输出；再次上滚可以暂停跟随。                                  |
| 外部更新和分页     | 外部新增历史不抢阅读位置；原生标题搜索、非空旧页签刷新及前向补载有先前真实界面与回归证据。        |
| 重启后的消息一致性 | 重启后重新展开工具，其输入、输出和公开进度与实时观察一致；同一原始会话没有重复导航入口。          |
| 退出时状态         | 页签空闲、草稿和队列为空，原会话 ID 映射保持。                                                    |
