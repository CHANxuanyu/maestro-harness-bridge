## 发布归档与复验

发布重构建版本为 `1.0.1-hb.3`。应用产品代码沿用 dev.4 的已验收实现；连接器去除固定个人 Node 路径、按标准安装位置寻址，并去掉不再使用的旧版启动路径。启动/检查/回退入口和可移植性修改通过独立合成测试、语法与包验证。

- 发布前运行仓库格式、ESLint、三项类型检查和回归；Linux / Windows CI 结果按对应提交保留。
- 从已提交源码完整构建 macOS arm64 应用，核对版本、commit、逐文件产物、原生 SQLite/PTY、签名与 ZIP；没有替换用户正在运行的安装或改写配置。
- 独立连接器包由仓库源码和锁定依赖生成，包含来源提交、文件 SHA-256、许可证、通用说明与可执行入口。验证不启动新的真实会话、不终止现有共享服务。
- Release 附件 `BUILD-MANIFEST.json` 与 `VERIFICATION.json` 记录本次真实结果和 GitHub CI 链接；`SHA256SUMS.txt` 覆盖发布资产。发布标签指向被验证的源码，不重复使用开发包的校验值。
- 发布包未重复原始聊天的完整 GUI 序列；它继承上述开发包的产品验收，另记录构建与可移植性复验，不能混称为同一个包。

## 已知限制

macOS Apple Silicon 预览，临时签名、未做 Apple Developer ID 公证。Linux / Windows CI 是自动回归，不是对应平台 GUI 或安装包验证。

共享模式仅验证 `codex-cli 0.163.0-alpha.11.1` 及文档指定的桌面布局；当前既有会话、同账户同主机、两端轮流发送。新会话、分支、远程共享和双端并发发送不支持。其他智能体配置和提供方不等同通过完整双端实机验收。需单独启用共享启动器，普通安装不会自动配置。

Stop 的对话中断和随后接续通过；等待工具后来自然退出，不能声称子进程立即被杀。History 摘要行为保留；未知元数据不补造；极窄窗口整页头栏和逐字流式刷新粒度未作完整重设计。
