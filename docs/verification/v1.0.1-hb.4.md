## 已知限制

- macOS Apple Silicon 预览，临时签名、未公证；其他平台 CI 不等同实际安装与界面验收。
- 回合按用户输入划分；未读数按显示行计算，折叠后可能减少。对话布局由回合折叠统一组织工具，“显示工具调用”的旧逐条折叠行为仅保留在智能体布局。
- 共享模式仍只支持指定 `codex-cli 0.163.0-alpha.11.1` 和桌面布局、同账户同主机的既有本地会话、两端顺序发送。未知版本、新建或分支、远程共享和并发发送不在支持范围。
- Stop 中断对话轮，不保证已启动终端进程立刻退出。History 摘要偏好不变，逐字流式粒度不保证与 Codex 一致。
- 本版完整原始同 ID 的新 GUI 回归、其他提供方等价验收和极窄窗口整页重设计未在本次发布中完成。
