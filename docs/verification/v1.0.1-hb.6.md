## 已知限制

- Apple Silicon macOS 预览，临时签名、未公证；其他平台没有本版安装与 GUI 验收。
- 运行中 `maestro-cli settings set` 若紧跟应用自身设置写入半秒内，窗口可能不更新；全新配置启动后很快退出，Claude 用量探针及其进程可能残留。这两项计划下一版修复。
- 桌面窗口保存不覆盖浏览器客户端，多个浏览器或桌面与浏览器同时改同一智能体仍以后写入者为准。退出保存总时限 5 秒，窗口交接保存最多 3 秒，失败或超时后仍继续，不保证故障窗口最后改动保存。
- 共享只准入固定版本、同账户同主机的既有本地 Codex 会话顺序接续；没有扩展到并发、新建、分支或远程共享。普通 Codex exec 在命令完成时提供输出，运行中增量仅属共享模式。
- Stop 按智能体停止，也影响同一智能体其他运行中的对话，不保证终端进程立即退出。自动跟随只覆盖当前可见、空闲且没有队列或自动恢复的本机标签，SSH 与隐藏窗口不在范围。
- 交接只携带文本和工具摘要；关于我逐文件写入，没有跨文件事务，新建向导与 `/wizard` 仍带全文。`native-history delete` 仅支持 Codex。
- DeepSeek 遗留历史路由、Codex 预览系统封装、交接草稿辨认仍有界面缺口；长历史实际绘制性能未测。Claude API 摘要残留 thinking 空壳的失败与处理边界见[公开版本说明](../release-notes/v1.0.1-hb.6.md#已知限制)。

## 交给 Opus 的界面复现

以下未完成的界面复现来自[核心体验完成记录](../roadmap/core-experience.md#完成记录)、[接口契约](../core-experience-contracts.md)及[前置项](hb6-prerequisites.md)，仍需在 hb.6 包复验，界面、文案和外观继续由 Opus 处理。

1. **DeepSeek 遗留历史：** 用专用测试智能体产生一轮后删除该智能体，从项目历史重开。核对是否建成缺少网关配置的普通 Claude 执行者；在确认路由前不发送。应保持可辨认的 DeepSeek 身份与正确账户，不能默默用 Claude 接着发。
2. **Codex 交接预览：** 发送一份交接草稿，在会话浏览器预览其首轮，再正常打开对话。对比预览是否多出 Maestro 系统封装；应一致呈现用户正文，保留原生文件。
3. **未发送草稿：** 准备交接但不发送，切到别的对话后回到侧栏。检查草稿是否仍只能看成“新建对话”，用户能否辨认并找回它；新增标识由 Opus 决定。
4. **向导提示：** 同步关于我后分别新建向导和 `/wizard`，对比普通对话的提示。向导仍带全文属于已知未完成项，不能把普通对话去重表述为所有入口都去重。
5. **Codex 输出与拒绝：** 普通 exec 执行长命令应持续显示运行状态，完成后展示完整输出；共享模式另验输出跟随与上滚。原生 effort 为 null 时显示未记录，显式 high 时显示 high。另一端结束后立即续接，若收到 active writer 拒绝，应保留输入并明确失败，不假报恢复、不删锁、不重试。
6. **多窗口退出：** 正常双窗口退出的脚本结果见上表；继续补验更新退出、无响应窗口和移动进行中的回合。记录每个窗口实际保存情况，不能用正常退出结果代替故障路径。
