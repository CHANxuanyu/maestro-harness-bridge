# 结果有效性

最终采用 `validated-*.json`，每项 7 次。两个版本在同轮交替 AB、BA，`beforeRef`、`afterRef` 和打包代码 SHA-256 指明被测对象。`validated-combined.json` 对比基准提交 `ad92dd648` 与三项优化后的 `2bdac429d`；其余文件分别隔离每项优化。

最初的 `baseline.json`、`codex-worktrees.json`、`codex-stat.json`、`native-project-paths.json` 原样保留测量数值，并增加失效说明和替代文件名。它们的完整项目发现确实覆盖 2000 份转录，但会话汇总只有 1750 条，压缩会话读取为 0 条，不能用于声称已测过压缩解析或完整 2000 条历史。

最终补充完整性断言时，旧语料在原代码上以 `1750 !== 2000` 失败。原因是压缩转录被放在 `archived_sessions`，项目发现支持这个目录，会话适配器只枚举日期树。本轮修正测试语料位置，保持断言，重新运行修改前及每项修改后的代码；没有改动产品发现范围，也没有删掉失败数据。该目录覆盖差异仍列为未修复限制。

JSON 为合成数据性能摘要，不含原生转录、账户路径或本机验收截图。Electron 结果尚未生成，默认跳过只证明门控有效。
